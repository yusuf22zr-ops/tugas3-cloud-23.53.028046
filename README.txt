ISI WEBSITE

- assets/images/   : ikon website

SEBELUM DIUNGGAH
1. Buka portofolio.html.
2. Cari dua tautan href="#" pada bagian Tugas 1 dan Tugas 2.
3. Ganti tanda # dengan tautan Google Drive atau tautan publik hasil tugas masing-masing.
4. Jika dosen meminta foto pribadi, siapkan file foto milik sendiri dan sesuaikan bagian ilustrasi/identitas pada index.html. Website saat ini menggunakan ilustrasi buatan CSS/SVG, bukan foto pribadi.

CARA MENJALANKAN LOKAL
- Ekstrak ZIP.
- Buka file index.html menggunakan browser.
- Periksa ketiga menu, tampilan, dan tautan portofolio.

CARA DEPLOY KE GITHUB PAGES
1. Buat repository publik bernama tugas3-cloud-2353028046.
2. Unggah seluruh isi folder ini ke bagian utama (root) repository. Pastikan index.html tidak berada di dalam subfolder tambahan.
3. Buka Settings > Pages.
4. Pada Build and deployment, pilih Deploy from a branch.
5. Pilih branch main dan folder /(root), lalu Save.
6. Tunggu sampai GitHub Pages menampilkan URL publik.
7. Buka URL tersebut melalui jendela privat dan ambil screenshot versi 1.

MEMBUAT VERSI 2
1. Ubah satu hal yang terlihat, misalnya warna utama di assets/css/style.css.
2. Simpan perubahan, lalu unggah/commit kembali dengan pesan "Pembaruan versi 2".
3. Tunggu proses deployment selesai.
4. Buka URL GitHub Pages yang sama, refresh, lalu ambil screenshot versi 2.

CATATAN
- Ganti tautan Tugas 1 dan Tugas 2 sebelum pengumpulan.
- Jangan unggah kata sandi, API key, atau data pribadi sensitif.
- Simpan screenshot bukti sesuai urutan pada instruksi dosen.
